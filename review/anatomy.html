If the octant glyphs below show as boxes, your browser font lacks Unicode 16 "Symbols for Legacy Computing Supplement". A terminal with the same gap shows the same boxes, and a width check cannot detect it.

Idea 1: aspect correction

A cell is about twice as tall as wide. A circle in cell units is a tall ellipse. The fix: radiusY = radiusX / 2. Cells below are drawn 1:2.

Uncorrected: radiusY = radiusX

Corrected: radiusY = radiusX / 2

gapPie, donut and radar apply this rule. The treemap does not. squarify() computes aspect ratios in cell units, so the measured "1.07 to 2.0" is in cell space, not on screen. The pie also takes height ≈ width / 2: 30 rows at 58 columns, 41 at 80.

Idea 2: sub-cell mosaics

Each cell is sampled as a 2×2, 2×3 or 2×4 grid. Bits are row-major: bit 0 upper-left, bit 1 upper-right, then down. The mask selects the glyph.

One octant cell: bit layout

Examples: 3 → 🮂 U+1FB82, 192 → ▂, 20 → 🯦 U+1FBE6, 1 → 𜺨 U+1CEA8. The octant block does not repeat patterns that exist in other blocks, so the table borrows from three blocks. Spot-checked from memory of the Unicode names, not fetched from the UCD.

"Width mismatches 0" proves one column per glyph. It does not prove the glyph is drawn: a missing glyph (tofu) is also one column. Octant is still the default for every caller.

Idea 3: two-colour boundary cells

A boundary cell shows two series: the glyph holds the winner (foreground) and the background holds the other. A cell has only two colour slots. At the rim there are three states (outside, A, B), so one must be dropped.

Why the tests stayed green

The suites check properties of the output. None checks that a label sits under its bar, that a drawn height matches its value, that a small value is visible, or what colour a run kind gets. None of the 137 checks (your count; I read the suites but did not run them) covers the red marks above. Add one test per slot family (the bar's x-centre equals its label's x-centre; drawn sub-rows equal value / sub-row unit ± 1), a golden snapshot of renders.txt, and tests for chunkFor.
